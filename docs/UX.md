# UX: не замыливать экран

Цель: игрок смотрит на HUD < 0.5 сек и знает, что делать дальше. Текст — враг.

## Принципы
1. **Одна полоска.** По умолчанию видно максимум 2 строки + таймер. Всё остальное спрятано.
2. **Глаголы и имена, без предложений.** «→ Грельвуд», «⚔ Хищник», «WP», а не «Идите в Грельвуд и активируйте точку телепортации».
3. **Показывать изменения, а не состояние.** Тосты на 3 сек при событии (новый уровень → что взять; новая зона → сплит). Потом исчезают.
4. **Цвет = смысл.** Зелёный — опережаешь PB, красный — отстаёшь, жёлтый — предупреждение. Больше цветов нет.
5. **Прозрачность для кликов всегда.** HUD никогда не перехватывает мышь в игре.
6. **Исчезать, когда не нужен.** Игра не в фокусе → HUD скрыт. В хайдауте/городе — приглушён (opacity 40%).
7. **Подробности по запросу.** Хоткей держишь — видишь панель деталей (следующие 3 шага, гемы, пассивки). Отпустил — пропала.

## Компоновка (по умолчанию — верх по центру, перетаскивается в режиме правки)
```
┌──────────────────────────────────────────────┐
│ A2 · 19   → Тропа Изменницы          1:12:40  │   строка 1: акт·ур. зоны, текущий шаг, игровое время
│           затем: Ворота Халани       −0:42   │   строка 2: следующий шаг (приглушённо), дельта к PB
└──────────────────────────────────────────────┘
        [ Ур. 12: +Быстрота · Ледяная стрела ]       тост 3 сек, под полосой
```
Предупреждение (одно) заменяет строку 2: «⚠ Ур. ниже зоны −4».

## Хоткеи (настраиваемые, по умолчанию)
| Клавиша | Действие |
|---|---|
| `Alt+Q` (держать) | панель деталей |
| `Alt+]` / `Alt+[` | шаг вперёд / назад (ручная коррекция) |
| `Alt+R` | сброс рана |
| `Alt+E` | режим правки: перетащить/масштаб, повтор — сохранить |
| `Alt+H` | скрыть/показать HUD |

## Визуал
- Шрифт крупный (по умолчанию 18px, масштаб 0.75–2.0), белый с тёмной обводкой; фон полосы — чёрный 55%.
- Без рамок, без заголовков, без иконок-кнопок. Скругление 8px.
- Анимации: только fade 150 мс.
