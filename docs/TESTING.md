# Тест в игре

## Подготовка
1. В игре: Настройки → Графика → Режим окна: **оконный полноэкранный** (в эксклюзивном полноэкранном HUD не виден).
2. Запустить `dist\PoE2Pilot\PoE2Pilot.exe`. Откроется консоль с логами — не закрывать, туда пишутся ошибки.
3. Откроется табло вылетов: выбрать билд, Enter. В трее появится значок PoE2 Pilot (правый клик: сменить билд, положение HUD, гемы, дерево, выход).
4. Переключиться в игру: HUD показывается только когда игра на переднем плане.

## Что проверить
| # | Действие | Ожидаемо |
|---|---|---|
| 1 | Новый персонаж Mercenary, войти в Берег реки | тост «Ран начат», подсказки уровня 1 (Twister, Tabula Rasa), таймер пошёл |
| 2 | Перейти в следующую зону | шаг маршрута сменился, полоска прогресса сдвинулась |
| 3 | Получить уровень | тост «Ур. N: …» с пассивкой; гемы/снаряжение — отдельными тостами |
| 4 | `Alt+Q` (держать) | панель деталей: снаряжение, связки, следующие шаги |
| 5 | `Alt+G` | окно гемов; наведение — описание; клик — имя в буфере, вставить в поиск игры (Ctrl+V) |
| 6 | `Alt+T` | дерево: взятое золотым, следующие узлы с номерами; взять пассивку — узел стал золотым |
| 7 | Взять пассивку не по плану | тост «Пассивки не по плану: 1», узел с красной обводкой |
| 8 | `Alt+E` | перетащить HUD мышью, колесо — масштаб, `Alt+E` ещё раз — сохранить |
| 9 | Закрыть и снова открыть PoE2Pilot.exe посреди забега | шаг, таймер, уровень и пассивки восстановились |
| 10 | Свернуть игру / Alt+Tab | HUD и окна скрылись |
| 11 | Клик по игре сквозь HUD | клик доходит до игры |

## Если что-то не так
- Скриншот + что делали + последние строки из консоли.
- Разбор забега после теста: `python -m pilot.core.analysis` (из папки проекта).
