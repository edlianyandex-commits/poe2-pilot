# Формат маршрута `data/routes/<id>.json`

```json
{
  "id": "campaign-0.5",
  "patch": "0.5.5",
  "title": "Кампания: базовый маршрут",
  "steps": [
    {
      "id": "a1-001",
      "act": 1,
      "area": "G1_1",
      "short": "⚔ Ривер → лагерь",
      "detail": "Босс в конце зоны, гем после квеста",
      "kind": "boss",
      "split": false,
      "done_on": {"enter": "G1_town"},
      "reward": "Uncut Skill Gem"
    }
  ]
}
```

| Поле | Обяз. | Правило |
|---|---|---|
| `id` | да | уникален в файле |
| `act` | да | 1–4 = акты, 101–103 = интерлюдии P1–P3 |
| `area` | да | ID зоны из лога (`data/areas/seen_areas_ru.tsv`), где выполняется шаг |
| `short` | да | ≤ 40 символов, без точки в конце, начинается с символа типа |
| `detail` | нет | ≤ 120 символов, показывается только в панели деталей |
| `short_en`, `detail_en` | нет | английский текст тех же полей, те же ограничения; при английском языке программы показываются они (у маршрута так же `title_en`) |
| `kind` | да | `move` → · `wp` ◆ · `boss` ⚔ · `quest` ! · `town` ⌂ · `trial` ✦ · `skip` ✕ |
| `split` | нет | true = сплит при выполнении шага |
| `done_on` | нет | `{"enter": "<area_id>"}` — шаг закрывается при первом входе в эту зону после старта шага. Нет поля → закрывается при входе в `area` следующего шага |
| `reward` | нет | ≤ 32 символа |

Символ в начале `short` = символ `kind` из таблицы (`→` допустим для `move`).
Имена в `short` — русские из `seen_areas_ru.tsv`; английские — в `data/areas/areas.json`.

```json
{"G1_1": {"act": 1, "level": 1, "ru": "Берег реки", "en": "Riverbank", "town": false, "has_wp": true}}
```
